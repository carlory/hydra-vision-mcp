# Security

Security fixes are maintained on `main`. Use a current tested snapshot or a release containing the relevant fix.

Report vulnerabilities privately using the repository's GitHub **Security > Report a vulnerability** feature when private vulnerability reporting is enabled. If unavailable, contact [carlory](https://github.com/carlory) to arrange a private report before sharing details. Do not put exploitable details, API keys, or private media in a public issue.

Include the affected version, reproduction steps, impact, and a sanitized sample where possible. The MCP process can read files available to its operating-system user and sends selected media to the configured provider. Run it with the file and network access you intend to grant, and use only providers you trust with that media.
